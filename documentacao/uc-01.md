# UC-01 — Cadastrar usuário

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário crie uma conta para utilizar o aplicativo.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-01 — Cadastro do usuário

* O usuário deve informar os dados obrigatórios para realizar o cadastro.
* Não deve ser permitido concluir o cadastro com campos obrigatórios vazios.

## Caso de uso: UC-01

### Pré-condições

* O aplicativo deve estar disponível.
* O usuário não deve estar autenticado.

### Gatilho

O usuário seleciona a opção de criar uma conta.

### Fluxo principal (sucesso)

1. O sistema apresenta o formulário de cadastro.
2. O usuário informa os dados obrigatórios.
3. O usuário confirma o cadastro.
4. O sistema valida os dados informados.
5. O sistema cria a conta do usuário.
6. O sistema informa que o cadastro foi realizado com sucesso.

### Pós-condições

* A conta do usuário é criada.
* O usuário pode utilizar os dados cadastrados para entrar no aplicativo.

## Cenários de validação

### CT-01 — Cadastro realizado com sucesso

**Dado** que o usuário informou todos os campos obrigatórios.

**Quando** confirmar o cadastro.

**Então** o sistema deve criar a conta e informar que o cadastro foi realizado com sucesso.

### CT-02 — Campo obrigatório vazio

**Dado** que existe um campo obrigatório vazio.

**Quando** o usuário tentar concluir o cadastro.

**Então** o sistema deve impedir o cadastro e solicitar o preenchimento dos campos obrigatórios.
