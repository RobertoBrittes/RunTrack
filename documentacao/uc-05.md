# UC-05 — Consultar histórico de treinos

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário consulte os treinos realizados anteriormente e visualize seus detalhes.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-08 — Acesso aos dados

* Cada usuário poderá visualizar seus próprios treinos.
* Os registros devem estar associados ao usuário que os realizou.

## Caso de uso: UC-05

### Pré-condições

* O usuário deve estar autenticado.
* Deve existir pelo menos um treino realizado.

### Gatilho

O usuário acessa a área de histórico.

### Fluxo principal (sucesso)

1. O sistema consulta os treinos realizados pelo usuário.
2. O sistema apresenta os registros em ordem organizada.
3. O usuário seleciona um treino.
4. O sistema apresenta os detalhes do treino selecionado.

### Pós-condições

* O usuário visualiza o histórico e os detalhes dos treinos realizados.

## Cenários de validação

### CT-01 — Consultar histórico

**Dado** que existem treinos realizados.

**Quando** o usuário acessar o histórico.

**Então** o sistema deve apresentar os registros.

### CT-02 — Visualizar detalhes

**Dado** que o histórico apresenta um treino.

**Quando** o usuário selecionar o treino.

**Então** o sistema deve apresentar seus dados e detalhes.

### CT-03 — Histórico vazio

**Dado** que o usuário não possui treinos realizados.

**Quando** acessar o histórico.

**Então** o sistema deve informar que não existem registros.
