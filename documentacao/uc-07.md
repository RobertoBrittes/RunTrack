# UC-07 — Visualizar resumo dos treinos

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário visualize informações resumidas sobre seus treinos realizados.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-07 — Cálculo do ritmo médio

* O ritmo médio dos treinos deve ser calculado utilizando a duração e a distância registradas.

### RN-08 — Acesso aos dados

* O resumo deve considerar somente os treinos do usuário.

## Caso de uso: UC-07

### Pré-condições

* O usuário deve estar autenticado.
* Deve existir pelo menos um treino realizado.

### Gatilho

O usuário acessa a área de resumo dos treinos.

### Fluxo principal (sucesso)

1. O sistema consulta os treinos realizados pelo usuário.
2. O sistema calcula os dados do resumo.
3. O sistema apresenta a distância total.
4. O sistema apresenta o tempo total.
5. O sistema apresenta a quantidade de treinos.
6. O sistema apresenta o ritmo médio.
7. O sistema apresenta a distribuição dos tipos de treino.

### Pós-condições

* O usuário visualiza um resumo atualizado dos seus treinamentos.

## Cenários de validação

### CT-01 — Visualizar resumo

**Dado** que o usuário possui treinos realizados.

**Quando** acessar a área de resumo.

**Então** o sistema deve apresentar os indicadores calculados a partir dos registros armazenados.

### CT-02 — Sem treinos realizados

**Dado** que o usuário não possui treinos realizados.

**Quando** acessar a área de resumo.

**Então** o sistema deve informar que ainda não existem dados para apresentar o resumo.
