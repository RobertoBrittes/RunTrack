# UC-03 — Gerenciar treinos

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário crie, consulte, edite e remova seus treinos personalizados.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-02 — Tipo de treino

* Cada treino deve possuir um tipo.
* Os tipos poderão incluir:

  * Corrida leve;
  * Corrida moderada;
  * Longo;
  * Intervalado (tiros);
  * Tempo/Ritmo;
  * Fartlek;
  * Recuperação;
  * Outro.

### RN-03 — Detalhamento do treino

* O usuário poderá definir a estrutura do treino de acordo com o tipo escolhido.
* O treino poderá possuir descrição, distância planejada, duração planejada, repetições, ritmo planejado e recuperação.

### RN-08 — Acesso aos dados

* Cada usuário poderá visualizar seus próprios treinos.
* Os treinos cadastrados devem estar associados ao usuário que os criou.

## Caso de uso: UC-03

### Pré-condições

* O usuário deve estar autenticado.

### Gatilho

O usuário acessa a área de treinos.

### Fluxo principal (sucesso)

1. O sistema apresenta os treinos cadastrados pelo usuário.
2. O usuário seleciona a opção de criar um novo treino ou selecionar um treino existente.
3. Para criar um treino, o usuário informa o nome, tipo e detalhes.
4. O sistema valida as informações.
5. O sistema salva o novo treino.
6. Para um treino existente, o usuário pode consultar seus detalhes.
7. O usuário pode editar as informações do treino.
8. O sistema salva as alterações realizadas.
9. O usuário pode solicitar a remoção de um treino.
10. O sistema solicita a confirmação da remoção.
11. Após a confirmação, o sistema remove o treino.

### Pós-condições

* Os treinos do usuário ficam cadastrados e atualizados no sistema.

## Cenários de validação

### CT-01 — Criar treino

**Dado** que o usuário está autenticado.

**Quando** informar os dados necessários e salvar.

**Então** o sistema deve criar o treino e apresentá-lo na lista.

### CT-02 — Editar treino

**Dado** que existe um treino cadastrado.

**Quando** o usuário alterar suas informações e salvar.

**Então** o sistema deve atualizar o treino.

### CT-03 — Remover treino

**Dado** que existe um treino cadastrado.

**Quando** o usuário solicitar e confirmar a remoção.

**Então** o sistema deve remover o treino da lista.

### CT-04 — Tipo não informado

**Dado** que o usuário não selecionou um tipo de treino.

**Quando** tentar salvar o treino.

**Então** o sistema deve impedir o cadastro e solicitar a seleção de um tipo.
