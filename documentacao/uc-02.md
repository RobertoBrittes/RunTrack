# UC-02 — Entrar no aplicativo

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário acesse o aplicativo utilizando seus dados cadastrados.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-01 — Cadastro do usuário

* O usuário deve possuir uma conta cadastrada para acessar o aplicativo.

## Caso de uso: UC-02

### Pré-condições

* O usuário deve possuir uma conta cadastrada.
* O usuário não deve estar autenticado.

### Gatilho

O usuário acessa a tela de entrada do aplicativo.

### Fluxo principal (sucesso)

1. O sistema apresenta a tela de entrada.
2. O usuário informa seus dados cadastrados.
3. O usuário confirma a entrada.
4. O sistema valida os dados.
5. O sistema permite o acesso ao aplicativo.

### Pós-condições

* O usuário está autenticado no RunTrack.

## Cenários de validação

### CT-01 — Entrada realizada com sucesso

**Dado** que o usuário possui uma conta e informa dados válidos.

**Quando** confirmar a entrada.

**Então** o sistema deve permitir o acesso ao aplicativo.

### CT-02 — Dados inválidos

**Dado** que o usuário informa dados incorretos.

**Quando** tentar entrar.

**Então** o sistema deve impedir o acesso e informar que os dados são inválidos.
