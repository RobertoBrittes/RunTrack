# UC-06 — Filtrar histórico por período

**Produto:** RunTrack

**Objetivo:** Permitir que o usuário consulte somente os treinos realizados dentro de um período específico.

## Atores

* **Usuário**
* **Sistema**

## Regras de negócio aplicadas

### RN-08 — Acesso aos dados

* O usuário poderá consultar somente seus próprios registros.

## Caso de uso: UC-06

### Pré-condições

* O usuário deve estar autenticado.
* O usuário deve possuir registros de treinos realizados.

### Gatilho

O usuário seleciona uma opção de filtro no histórico.

### Fluxo principal (sucesso)

1. O sistema apresenta as opções de período.
2. O usuário seleciona o período desejado.
3. O sistema consulta os registros correspondentes.
4. O sistema apresenta os treinos encontrados.

### Pós-condições

* O histórico é apresentado de acordo com o período selecionado.

## Cenários de validação

### CT-01 — Filtrar com resultados

**Dado** que existem treinos realizados no período selecionado.

**Quando** o usuário aplicar o filtro.

**Então** o sistema deve apresentar os treinos correspondentes.

### CT-02 — Filtrar sem resultados

**Dado** que não existem treinos realizados no período selecionado.

**Quando** o usuário aplicar o filtro.

**Então** o sistema deve informar que não existem registros para o período.
